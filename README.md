# 🎓 Student Hub Portal

> **Connect. Learn. Grow.**

Student Hub Portal is a frontend web development project designed to provide students with a single platform to access their academic information and useful student services.

## 📌 About the Project

The **Student Hub Portal** provides a simple and organized interface where students can access important academic information such as courses, assignments, attendance, results, timetable, announcements, and notifications.

The project is developed using **HTML, CSS, and JavaScript**, with separate folders for better organization of the website.

## ✨ Features

- 🏠 **Dashboard** – Quick overview of student information
- 📚 **Courses** – View courses and course details
- 📝 **Assignments** – View and submit assignments
- 📅 **Timetable** – View class schedules
- 📊 **Attendance** – Check attendance information
- 📈 **Results & Grade Card** – View academic performance
- 📢 **Announcements** – Stay updated with important notices
- 🔔 **Notifications** – Receive important updates
- 👤 **Profile** – View and edit student information
- ⚙️ **Settings** – Manage account preferences
- 🔐 **Login & Password Management** – Login, change password and recover password
- 🌓 **Light/Dark Theme** – Switch between light and dark modes
- 📱 **Responsive Navigation** – Hamburger menu for easy navigation
